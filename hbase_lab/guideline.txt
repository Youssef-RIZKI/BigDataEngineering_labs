-----------------------------------------------------------------------------------
-------- HBASE FILTERS -----------------------------------------------------------  
-----------------------------------------------------------------------------------

1 Row filter: 
    scan 'sales_ledger', {FILTER => "RowFilter (>,'binary:102')"}  -- be carefull to the spaces 

2. Family Filter 
    scan 'sales_ledger', {FILTER=> "FamilyFilter(!=, 'binary:customer')"}

3.Column Filter (QualifierFilter) : select product from sales_ledger
    scan 'sales_ledger', {FILTER=> "QualifierFilter(=, 'binary:product')"}
4. Value Filter:
    scan 'sales_ledger', {FILTER=> "ValueFilter(=, 'substring:Desk')"}
5.Single column value filter : -- select * from sales_ledger where product like '%Desk%'
    scan 'sales_ledger', {FILTER=>"SingleColumnValueFilter('sales', 'product', =, 'substring:Desk')"}
6.Prefix Filter : select * from sales_ledger where id like '10%'
    -- scan 'sales_ledger' : {FILTER=> "PrefixFilter('10)"}
7. Page Filter : limit the number of raws returned 
    --scan 'sales_ledger', {FILTER =>"PageFilter(2)"}
    -- scan 'sales_ledger', {LIMIT => 10}

------------------------------------------------------------------------------------
------------- FILE LOADING FROM HDFS TO HBASE 
------------------------------------------------------------------------------------
1.for each row in the purchases.txt file, add a row number at the beginning, then put the result at new file named purchases2.txt 
    Get-Content purchases.txt | ForEach-Object -Begin {$i=1} -Process {
        "$i`t$_"
        $i++
    } > purchases2.txt

2.put the purchases2.txt file in the input folder in hdfs.
    First, make sure to have the file purchases2.txt encoded in utf-8
        -- file purchases2.txt 
    if this is not the case then type this command:
        -- iconv -f UTF-16 -t UTF-8 /shared_volume/purchases2.txt -o /shared_volume/purchases2_utf8.txt 
        drop the old file and rename the new one to purchases2.txt 
    then, load the file to hdfs using the commad:
        -- hdfs dfs -put /shared_volume/purchases2.txt ./input
3.using the ImportTsv command load the content of the file purchases2.txt into the hbase table products
    hbase org.apache.hadoop.hbase.mapreduce.ImportTsv \
    -libjars /usr/local/hbase/lib/commons-lang-2.6.jar \
    -Dimporttsv.columns=HBASE_ROW_KEY,cf:date,cf:time,cf:town,cf:product,cf:price,cf:payment \
    products /user/root/input/purchases2.txt
4. list the content of the products table : 
    -- scan 'products'
    -- get 'products',8,{COLUMN =>'cf:town'}
    cf:town                                        timestamp=1763459920699, value=New York
